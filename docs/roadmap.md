# Roadmap

## Phase 1: Core shell

- Browser form detection and snapshotting.
- Local backend with field analysis and draft generation.
- Shared contracts and a stable message protocol.

## Phase 2: Document understanding

- Resume and CV parsing.
- Certificate and portfolio ingestion.
- Structured profile synthesis with evidence links.

## Phase 3: Better autofill

- Multi-step form tracking.
- Dynamic DOM and shadow DOM resilience.
- Select/radio/textarea/rich-text specialization.
- Confidence-based direct fill versus review-only suggestions.

## Phase 4: Memory and learning

- Persistent answer memory.
- Application history and consistency checks.
- User style preferences and company-aware tone adaptation.

## Phase 5: SaaS hardening

- Multi-tenant storage.
- Authentication and encrypted secret handling.
- Telemetry, observability, and audit logs.
- Deployable cloud backend with local fallback.
